# UniDock V0.2 UI 设计 Spec

## 当前状态

本文件记录 UniDock V0.2 Demo 已确认的 UI 和交互方案，供研发部正式实现参考。

当前 V0.2 Demo 位于：

- `demo/unidock-v02-demo.html`

注意：Demo 只用于确认界面和流程，不涉及真实后端、登录、云同步或正式技术方案。

## V0.2 设计目标

V0.2 的目标是把 MVP 从固定工作台推进为更适合个人日常使用的本地工具。

本版 UI 重点：

1. Todo 支持截止日期和截止时间。
2. 新增个人信息页。
3. Home 中的“课表”升级为更通用的“日程”。
4. 日程支持手动添加、编辑和删除事件。
5. Links 分栏页支持搜索。
6. Current Student Website 加入学校事务分类。

设计边界：

- 不做登录。
- 不做云同步。
- 不做自动爬取 Allocate+。
- 不做邮箱自动读取。
- 不做 AI 邮件助手正式接入。
- 不做移动端 App。

## 信息架构

### 左侧导航

V0.2 左侧导航为：

1. Home
2. 学习相关
3. 学校事务
4. 生活支持
5. 联系与帮助
6. 校园生活
7. 账号工具
8. 个人信息 / 设置

“个人信息 / 设置”放在左侧底部，与学校入口分类分隔，表示它是 UniDock 本地配置页，而不是学校网站入口。

### 页面状态

用户感知上分为三类页面：

- Home 工作台
- 学校入口分栏页
- 个人信息 / 设置页

Home 页显示：

- 顶部概览
- 本周日程
- 待办事项
- 高频入口快捷按钮

学校入口分栏页显示：

- 当前分类标题
- 搜索框
- 当前分类或搜索结果 Links

个人信息 / 设置页显示：

- 基础资料表单

当前 V0.2 Demo 已移除“常用入口偏好”和“默认显示设置”两个设置区。

## Home 页

### 顶部概览区

文案：

- Kicker：个人学习工作台
- 标题：今天要看的东西
- 说明：这里是 Home 页，只放本周日程、待办事项和常用入口。

顶部快捷入口当前保持静态展示：

- Moodle
- Student Email
- Allocate+
- Current Student Website

### 工作区布局

Home 页主工作区为左右两栏：

- 左侧：本周日程
- 右侧：待办事项

布局要求：

- 日程面板和 Todo 面板高度保持一致。
- 无论当前内容多少，整体应用窗口大小保持稳定。
- 内容少的分栏页也不能让主窗口明显缩短。
- 内容超出时在内容区域内部滚动。

## 本周日程

### 命名

V0.2 不再使用“课表”作为主模块名称，统一改为“日程”。

原因：

- 日程不只包含课程。
- 用户可能手动添加兼职、预约、活动或其他个人安排。

可见文案：

- 本周日程
- 添加日程
- 编辑日程
- 新增事件
- 编辑事件
- 删除事件
- 保存事件
- 事件详情

学校链接说明中仍可保留“课程 / 课表”，例如 Moodle 和 Allocate+，因为那是对应学校系统的实际用途。

### 日程视图

日程采用周视图时间轴：

- 顶部：周一到周五。
- 左侧：时间轴。
- 中间：事件卡片按星期和时间定位。
- 当前日期列轻微高亮。
- 不同时间的事件纵向位置不同。

### 事件卡片

事件卡片展示：

- 事件名称
- 开始时间和结束时间
- 地点

点击事件卡片：

- 弹出居中的事件详情卡片。
- 详情中显示时间、地点。
- 提供编辑和删除入口。

### 添加日程

Home 日程模块右上角按钮文案为：

- 添加日程

点击后打开右侧抽屉。

抽屉用途：

- 查看已有事件列表。
- 新增事件。
- 编辑已有事件。
- 删除事件。

抽屉标题仍可用“编辑日程”，因为抽屉是日程管理区域；主按钮强调“添加日程”。

### 事件表单

字段：

- 事件名称
- 星期
- 开始时间
- 结束时间
- 地点

校验建议：

- 事件名称必填。
- 开始时间早于结束时间。
- 星期必选。

## Todo 模块

### 列表展示

Todo 列表项展示：

- 完成状态按钮
- 待办标题
- 截止状态标签

完成状态按钮要求：

- 尺寸明显大于默认 checkbox。
- 点击区域足够清晰。
- 点击 checkbox 只切换完成状态，不打开详情。

截止状态：

- 已逾期
- 今天
- 明天
- 无截止时间
- 已完成

排序说明固定显示：

- 自动排序：未完成优先，按截止时间排列

### 新增 Todo

Todo 面板右上角提供：

- 新增待办

点击后，在页面中间弹出添加卡片。

添加卡片字段：

- 待办内容
- 截止日期
- 截止时间

截止日期和截止时间可留空。

### 编辑 Todo

列表中不显示单独的“编辑”按钮。

点击整张 Todo 卡片：

- 在页面中间弹出待办详情卡片。
- 卡片自动处于可编辑状态。
- 用户可修改内容、截止日期和截止时间。

交互边界：

- 点击 Todo 左侧完成按钮只切换完成状态。
- 点击 Todo 卡片其他区域打开详情编辑。

## 学校入口分栏页

### 分类页

点击左侧分类后进入对应分栏页。

分栏页显示：

- 顶部概览区
- Links 面板
- 搜索框
- 当前分类链接或搜索结果

分栏页不显示：

- 日程
- Todo
- 个人信息表单

### 搜索

搜索框位置：

- Links 面板顶部。

搜索文案：

- 搜索学校入口、说明或分类

搜索范围：

- 链接名称
- 链接说明
- 所属分类

搜索结果为空时：

- 显示“没有找到相关入口”。

### Current Student Website

加入“学校事务”分类。

展示名称：

- Current Student Website

说明：

- 查看 UNSW College 当前学生的重要信息与服务入口。

## 个人信息 / 设置页

当前 V0.2 Demo 中，个人信息页只保留基础资料。

字段：

- 昵称或姓名
- zID
- Program / Course
- Term / Intake
- Student Email
- Campus
- 备注

文案要求：

- 明确说明这些信息只保存在本地浏览器中。

已移除：

- 常用入口偏好
- 默认显示设置

原因：

- 当前 Demo 阶段先保持设置页轻量。
- 避免过早引入偏好管理复杂度。

## 视觉与布局要求

整体风格继续保持：

- 清爽
- 安静
- 有秩序
- 工作台感

关键要求：

1. 不做营销页。
2. Home 页不要堆满表单。
3. 日程和 Todo 是 Home 的核心。
4. 事件和 Todo 的新增/编辑使用弹窗或抽屉承载。
5. 应用窗口高度保持稳定，不随内容多少明显变化。
6. 日程面板和 Todo 面板高度一致。

## 本地配置边界

V0.2 Demo 中的所有数据均为模拟数据。

正式实现时可本地保存：

- Todo 内容、完成状态、截止日期和截止时间
- 个人资料
- 日程事件

明确不做：

- 登录系统
- 云端同步
- 自动导入课表
- 自动读取邮箱
- 自动生成 Todo
- AI 助手接入

## 组件建议

正式实现可在现有组件基础上调整：

- HomeDashboard
- WeeklyScheduleTimeline 改名或扩展为 WeeklyAgendaTimeline
- CourseBlock 改名或扩展为 AgendaEventBlock
- CoursePreviewModal 改名或扩展为 AgendaEventModal
- ScheduleEditDrawer 改名或扩展为 AgendaEditDrawer
- TodoPanel
- TodoDetailModal
- DueStatusBadge
- LinkPage
- LinkSearchBar
- ProfileSettingsPage
- ProfileForm

## 验收标准

V0.2 UI 完成后应满足：

1. Home 页显示“本周日程”，不再显示“本周课表”作为主模块名。
2. 日程按钮为“添加日程”。
3. 可通过抽屉新增、编辑、删除日程事件。
4. 日程事件可包含课程、兼职、预约等任意安排。
5. Todo 点击“新增待办”后，在页面中间弹出添加卡片。
6. Todo 列表不显示单独编辑按钮。
7. 点击 Todo 卡片打开居中详情，并直接可编辑。
8. 点击 Todo 完成按钮只切换完成状态。
9. Todo 完成按钮尺寸清晰可点。
10. 日程面板和 Todo 面板高度一致。
11. 应用窗口高度保持稳定，不因分栏页内容少而缩短。
12. 个人信息页只保留基础资料。
13. Links 分栏页支持搜索。
14. Current Student Website 位于学校事务分类。

## 当前 UI 结论

V0.2 Demo 已稳定为：

- Home：本周日程 + Todo
- Links 分栏页：分类入口 + 搜索
- 个人信息 / 设置：基础资料

正式研发应以 `demo/unidock-v02-demo.html` 和本文件为 V0.2 UI / 交互基准。
