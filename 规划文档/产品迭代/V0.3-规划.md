# UniDock V0.3 规划

## 版本定位

UniDock V0.3 的目标是把 Todo 从“单一待办列表”升级为更接近学习任务中心的能力，并引入低风险的邮件分析助手。

V0.3 不继续扩展学校入口导航，也不处理常用入口置顶。`ISSUE-004` 继续保持 Deferred。

## 产品目标

V0.3 重点解决两个问题：

1. Todo 数量增加后，单一列表不利于用户判断今天要做什么、未来计划是什么、哪些已经完成。
2. 邮件、通知和消息中经常包含作业、预约、截止日期、材料要求和生活事项，需要一个低风险方式辅助用户提取 Todo。

## V0.3 核心范围

### 1. Todo 系统视图

#### 目标

参考 Apple 提醒事项的系统视图，将 Todo 按状态和截止时间组织为更容易理解的任务视图。

#### 视图范围

V0.3 做四个系统视图：

- 计划
- 今天
- 全部
- 完成

#### 计划

展示有截止时间，且截止日期在未来的未完成 Todo。

用途：

- 帮助用户看到接下来要准备的事项。

#### 今天

展示今天截止的未完成 Todo。

建议同时展示已逾期但未完成的 Todo，避免用户漏掉重要事项。

用途：

- 帮助用户判断今天最需要处理什么。

#### 全部

展示所有 Todo，包括未完成和已完成。

用途：

- 提供完整总览。

#### 完成

展示所有已完成 Todo。

用途：

- 作为完成事项归档视图。

#### 交互建议

- Todo 面板顶部增加视图切换。
- 每个视图显示数量。
- 新增 Todo、编辑 Todo、删除 Todo 的能力保持不变。
- Todo 排序继续沿用 V0.2 的截止时间排序逻辑。

#### 暂不支持

- 用户自定义分类
- 自定义列表
- 项目分组
- 标签
- 优先级
- 重复任务

### 2. 邮件分析助手

#### 目标

帮助用户从邮件、通知或消息中提取可能的学习任务、生活事项、截止日期和行动项，并生成 Todo 建议。

#### 当前策略

V0.3 不接入真实邮箱，不做邮箱授权，也不自动读取邮件。

采用低风险流程：

1. 用户手动粘贴一封邮件内容。
2. 用户点击分析。
3. 系统生成 Todo 建议。
4. 用户检查、勾选或修改建议。
5. 用户确认后添加到 Todo。

#### 建议识别内容

邮件分析助手优先识别：

- 作业或任务名称
- 截止日期
- 截止时间
- 课程或来源
- 需要准备的材料
- 预约、会议或活动安排
- 生活、住宿、社团或个人行政事项

#### UI 入口建议

邮件分析助手建议作为 Todo 能力的一部分，而不是新增大型独立页面。

入口可以放在：

- Todo 面板中的“从邮件生成”

#### 结果展示

分析结果以 Todo 建议列表展示。

每条建议应支持：

- 勾选是否添加
- 编辑标题
- 编辑截止日期
- 编辑截止时间

用户点击确认后，选中的建议加入 Todo。

#### 暂不支持

- 自动读取邮箱
- 邮箱授权
- 后台定时扫描
- 自动添加 Todo
- 邮件分析历史
- 附件读取
- 多邮箱支持

## 优先级

### P0

- Todo 系统视图：计划 / 今天 / 全部 / 完成。
- 邮件粘贴分析生成 Todo 建议。
- 用户确认后添加 Todo。

### P1

- 每个 Todo 视图显示数量。
- 邮件分析结果可编辑。
- 单封邮件支持生成多个 Todo 建议。

### P2

- 邮件分析历史。
- 自动识别课程名称。
- 自动识别材料要求。

## V0.3 非目标

V0.3 暂不做：

- 常用入口置顶
- 用户自定义 Todo 分类
- Todo 优先级
- 重复任务
- 真实邮箱读取
- 邮箱授权
- 自动添加 Todo
- 自动课表导入
- 登录系统
- 云同步

## 与已有版本关系

V0.2 已完成：

- 本周日程
- 日程手动编辑
- Todo 截止日期和截止时间
- Todo 新增、编辑、删除
- Links 搜索
- 个人信息本地保存

V0.3 在此基础上继续增强 Todo，而不是继续扩大导航入口。

## 当前产品结论

UniDock V0.3 应围绕 Todo 做深，重点不是增加更多入口，而是让用户更容易管理学习任务。

推荐 V0.3 核心范围：

1. Todo 系统视图。
2. 邮件粘贴分析助手。

`ISSUE-004` 常用入口置顶继续暂缓，不进入 V0.3。
