# UniDock MVP 首页 UI 设计 Spec

## 设计目标

UniDock MVP 首页定位为 UNSW / UNSW College 新生的个人学习工作台。

页面需要让用户打开后立刻完成三件事：

1. 看清本周课程安排。
2. 记录和处理基础待办事项。
3. 通过左侧分类导航快速进入学校相关网站。

MVP 不做复杂门户、后台管理或多页面系统。首页就是第一版核心产品。

## 页面结构

### 桌面端布局

桌面端采用左侧固定导航 + 右侧工作台布局。

- 左侧导航栏宽度：约 240px。
- 右侧主内容区：自适应宽度，最大内容宽度建议 1200px。
- 页面背景：浅灰白工作台背景。
- 内容区采用上下结构：
  - 顶部：页面标题、日期、快捷入口。
  - 中部：一周课表。
  - 右侧或下方：待办事项。
  - 底部：当前分类下的学校链接。

推荐桌面端主内容网格：

- 左侧主列：一周课表，占约 65%。
- 右侧辅列：待办事项，占约 35%。
- 分类链接区横跨主内容宽度，位于课表和待办下方。

### 移动端布局

移动端不保留常驻左侧栏。

- 顶部显示页面标题和菜单按钮。
- 分类导航收进抽屉或横向分段导航。
- 内容顺序：
  1. 今日概览
  2. 一周课表
  3. 待办事项
  4. 分类链接

移动端第一版只要求可用和清晰，不要求复杂动效。

## 用户主流程

### 查看课程

1. 用户进入首页。
2. 默认看到本周课表。
3. 用户扫视星期、时间、课程名和地点。
4. 如需进入学校课表系统，可点击 Allocate+ 链接。

### 处理待办

1. 用户在待办输入框输入事项。
2. 点击新增按钮或按 Enter 添加。
3. 用户可勾选完成状态。
4. 用户可删除单条待办。

### 查找学校入口

1. 用户点击左侧分类。
2. 主内容区链接区刷新为该分类下的入口。
3. 用户点击链接卡片。
4. 链接在新标签页打开对应学校页面。

## 页面区域设计

### 左侧导航栏

#### 内容

导航栏包含品牌区和分类区。

品牌区：

- 主标题：UniDock
- 副标题：UNSW student hub

分类区：

1. 学习相关
2. 学校事务
3. 生活支持
4. 联系与帮助
5. 校园生活
6. 账号工具

#### 交互

- 当前选中分类使用高亮背景和左侧强调条。
- 点击分类后，右侧链接区展示对应内容。
- 分类项应包含图标、中文分类名、可选英文辅助名。

#### 推荐图标

- 学习相关：BookOpen
- 学校事务：FileText
- 生活支持：HeartHandshake
- 联系与帮助：CircleHelp
- 校园生活：Map
- 账号工具：KeyRound

如使用 lucide 图标库，优先采用上述图标。

### 顶部概览区

#### 内容

- 标题：今天要看的东西
- 副标题：课程、待办和学校入口都放在这里。
- 当前日期：例如 Friday, 18 Sep
- 快捷链接：
  - Moodle
  - Student Email
  - Allocate+

#### 设计说明

顶部概览区不做大幅 hero。它应该像工作台的头部工具区，紧凑、清楚、可扫视。

### 一周课表模块

#### 模块标题

本周课表

#### 信息字段

每节课展示：

- 课程名称
- 星期
- 开始时间
- 结束时间
- 地点

#### 推荐布局

课表采用按星期分组的列表或表格。

桌面端推荐按五列展示：

- Mon
- Tue
- Wed
- Thu
- Fri

每列内展示课程卡片。课程卡片内容：

- 课程名称
- 时间范围
- 地点

如果某一天没有课程，显示空状态：

今天没有已记录课程

#### 卡片状态

- 普通课程：白色卡片，浅边框。
- 当前日期列：列标题增加轻微强调。
- 当前正在进行的课程：可以使用轻色背景强调。

#### MVP 暂不包含

- 周切换
- 日历视图切换
- 自动同步
- 提醒
- 出勤记录

### 待办事项模块

#### 模块标题

待办事项

#### 信息字段

每条待办展示：

- 待办内容
- 完成状态

#### 操作

- 输入待办
- 新增待办
- 标记完成 / 取消完成
- 删除待办

#### 推荐布局

模块顶部：

- 单行输入框
- 右侧新增按钮，按钮文字：添加

列表区域：

- 左侧 checkbox
- 中间待办文本
- 右侧删除图标按钮

空状态：

还没有待办。把下一件要做的事写下来。

#### 交互细节

- 输入框为空时，添加按钮禁用。
- 按 Enter 可以新增待办。
- 已完成待办文字加删除线，并降低透明度。
- 删除按钮默认弱化，悬停或聚焦时明显。

### 分类链接模块

#### 模块标题

学校入口

标题右侧显示当前分类名，例如：

学校入口 / 学习相关

#### 链接卡片内容

每个入口使用一张小卡片展示：

- 链接名称
- 面向新生的简短说明
- 外部打开图标

点击整张卡片即可打开链接。

#### 分类与入口

学习相关：

- Moodle：课程资料、作业和学习内容入口。
- Allocate+：查看课表、选课和出勤相关信息。
- Academic Calendar：查看关键日期、假期和学期安排。
- Subject Enrolment Form：提交选课或科目登记相关表格。
- Student Progress Support：预约学业进度支持。

学校事务：

- Student Forms：查找并提交学生事务表格。
- Student ID Card：预约办理或更换学生卡。
- College Policies：查看学院政策和流程。
- FS UNSW Preferences：Foundation Studies 升学偏好相关入口。

生活支持：

- Accommodation Support：预约住宿相关支持。
- Wellbeing Support：预约身心健康支持。
- 24/7 Support on Campus：校园安全和紧急支持入口。

联系与帮助：

- Contact Us：不知道找谁时，从这里提交问题。
- Important Student Contacts：查看重要部门和支持联系方式。

校园生活：

- Campus Map：查找教室和校园地点。
- Events & Activities：查看校园活动和社团活动。
- Volunteering：查看志愿活动机会。

账号工具：

- Forgot zID Password：重置 zID 密码。
- Student Email：查看学校邮件和正式通知。

## 视觉风格

### 气质

整体风格应当是：

- 清爽
- 安静
- 有秩序
- 像个人学习工作台，而不是营销首页

避免使用夸张渐变、大面积装饰图、过大的宣传标题。

### 配色建议

基础色：

- 页面背景：#F6F7F9
- 主内容背景：#FFFFFF
- 主文字：#172033
- 次级文字：#667085
- 边框：#E4E7EC

强调色：

- 主色：#FFD500 或接近 UNSW 黄色
- 深色强调：#1F2937
- 成功状态：#12B76A
- 危险操作：#D92D20

使用 UNSW 黄色时要注意可读性。黄色更适合作为强调条、图标底色或选中状态，不建议承载浅色文字。

### 圆角与阴影

- 卡片圆角：8px。
- 按钮圆角：8px。
- 输入框圆角：8px。
- 阴影保持克制，可使用浅阴影或仅使用边框。

## 组件清单

研发部实现时建议拆成以下组件：

- AppShell：页面整体框架。
- SidebarNav：左侧分类导航。
- TopBar：顶部概览区。
- WeeklySchedule：一周课表。
- ScheduleDayColumn：单日课程列。
- CourseCard：课程卡片。
- TodoPanel：待办模块。
- TodoItem：待办列表项。
- LinkSection：分类链接区域。
- LinkCard：链接卡片。

## 响应式规则

- >= 1024px：左侧导航常驻，课表和待办双列展示。
- 768px - 1023px：左侧导航可缩窄，课表在上，待办在下或右侧较窄展示。
- < 768px：隐藏常驻侧栏，使用顶部菜单；所有模块单列堆叠。

## 文案规范

页面文案优先使用中文解释，保留学校入口原英文名称。

示例：

- Moodle：课程资料、作业和学习内容入口。
- Allocate+：查看课表、选课和出勤相关信息。
- Student Email：查看学校邮件和正式通知。

按钮文案：

- 添加
- 删除
- 打开

空状态文案：

- 今天没有已记录课程
- 还没有待办。把下一件要做的事写下来。
- 这个分类下暂时没有入口

## 数据与状态

### 课程数据结构建议

```ts
type Course = {
  id: string;
  name: string;
  weekday: 'mon' | 'tue' | 'wed' | 'thu' | 'fri' | 'sat' | 'sun';
  startTime: string;
  endTime: string;
  location: string;
};
```

### 待办数据结构建议

```ts
type Todo = {
  id: string;
  title: string;
  completed: boolean;
};
```

### 链接数据结构建议

```ts
type UniLink = {
  id: string;
  categoryId: string;
  title: string;
  description: string;
  url: string;
};
```

## MVP 验收标准

研发完成后，页面应满足：

1. 桌面端能看到左侧垂直分类导航。
2. 点击分类后，学校入口区域能切换对应链接。
3. 一周课表能按星期展示课程。
4. 待办事项支持新增、完成、取消完成和删除。
5. 外部链接点击后能打开对应学校网站。
6. 移动端页面不横向溢出，主要内容可顺序浏览。
7. 页面整体是工作台风格，不是营销落地页。

## 当前 UI 结论

UniDock MVP 首页采用「左侧分类导航 + 右侧学习工作台」结构。

第一版的视觉重点不是花哨，而是降低新生判断成本：一眼知道今天/本周有什么课、还有什么事要做，以及学校入口该从哪里进。
