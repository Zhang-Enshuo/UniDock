# V0.2 常用入口置顶能力未实现且产品规划与 UI 文档范围不一致

## 基本信息

- 编号：ISSUE-004
- 类型：讨论
- 优先级：中 / P1
- 当前状态：暂缓

## 背景说明

`规划文档/产品迭代/V0.2-规划.md` 已确认“链接搜索和常用入口置顶进入 V0.2”，并提到个人信息 / 设置页管理高频快捷入口偏好。但当前 `UI-V0.2-设计.md` 和实现中移除了“常用入口偏好”和“默认显示设置”，Home 顶部快捷入口仍为静态展示。

影响：V0.2 规划和实现范围不一致，需要产品部确认是补做置顶能力，还是正式调整 V0.2 范围并更新规划文档。

## 建议处理方式

- 当前暂缓处理，不直接进入研发实现。
- 待用户正式入学并积累真实使用经验后，再判断哪些入口属于高频常用入口。
- 后续若确认补做，再交研发实现常用入口置顶能力，或更新 V0.2 规划与 UI 文档以明确移出范围。
- 若确认补做，需要进一步明确置顶入口数量、管理位置、默认状态、localStorage 持久化策略和 Home 展示规则。
