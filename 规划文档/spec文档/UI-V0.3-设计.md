# UniDock V0.3 UI 设计 Spec

## 当前状态

本文件记录 UniDock V0.3 UI 方案，用于产品、UI 和研发对齐后续正式开发。

当前 V0.3 Demo 位于：

- `demo/unidock-v03-demo.html`

注意：Demo 只用于确认界面和操作流程，不涉及真实后端、邮箱授权、AI 接口、登录、云同步或正式技术方案。

## V0.3 设计目标

V0.3 在 V0.2 的基础上继续增强 Todo，而不是扩大学校入口导航。

本版 UI 重点：

1. 将 Todo 从单一列表升级为系统视图。
2. Home 默认展示“今天”视图，帮助用户判断当天要处理什么。
3. 增加“从邮件生成”入口，让用户手动粘贴邮件并生成 Todo 建议。
4. 邮件建议必须由用户检查、编辑并确认后才加入 Todo。

设计边界：

- 不做真实邮箱读取。
- 不做邮箱授权。
- 不做后台扫描。
- 不做自动添加 Todo。
- 不做邮件分析历史。
- 不做自定义 Todo 分类。
- 不做标签、优先级或重复任务。
- 不做云同步。

## 信息架构

V0.3 不新增左侧导航大类。

Home 页仍然保持 V0.2 的主结构：

- 左侧：本周日程
- 右侧：Todo / 待办事项

V0.3 的主要变化集中在右侧 Todo 面板内部。

学校入口分栏页、个人信息 / 设置页沿用 V0.2 方案。

## Home 页 Todo 面板

### 默认视图

Home 打开后，Todo 面板默认选中：

- 今天

“今天”视图包含：

- 今天截止的未完成 Todo。
- 已逾期但未完成的 Todo。

原因：

- Home 的核心语义是“今天要看的东西”。
- 已逾期事项如果不进入今天视图，用户容易漏处理。

### 顶部操作

Todo 面板右上角提供两个操作：

- 从邮件生成
- 新增待办

“从邮件生成”放在 Todo 面板内，而不是左侧导航或独立页面中。

原因：

- 邮件分析助手本质是 Todo 的创建方式之一。
- V0.3 不希望把低风险邮件分析做成大型独立模块。

### 系统视图切换

Todo 面板内增加四个系统视图：

- 今天
- 计划
- 完成
- 全部

每个视图显示数量。

建议呈现为分段按钮或紧凑 tab，而不是二级导航。

### 视图规则

#### 今天

展示今天截止的未完成 Todo，以及已逾期但未完成的 Todo。

#### 计划

展示未来有截止日期的未完成 Todo。

不展示：

- 无截止时间 Todo。
- 已完成 Todo。
- 今天或已逾期 Todo。

#### 完成

展示所有已完成 Todo。

#### 全部

展示所有 Todo，包括未完成和已完成。

### Todo 卡片样式

四个系统视图中的 Todo 卡片保持同一种样式。

不因为视图不同改变卡片结构。

卡片继续展示：

- 完成状态按钮
- 待办标题
- 截止状态标签

截止状态标签包括：

- 已逾期
- 今天
- 明天
- 未来日期
- 无截止时间
- 已完成

完成状态按钮要求沿用 V0.2：

- 尺寸明显大于默认 checkbox。
- 点击区域清晰。
- 点击 checkbox 只切换完成状态，不打开详情。

点击 Todo 卡片：

- 打开居中的待办详情卡片。
- 进入可编辑状态。
- 不在列表中展示单独“编辑”按钮。

### 排序

V0.3 继续沿用 V0.2 的排序逻辑：

- 未完成优先。
- 按截止时间排列。
- 已完成进入完成视图或全部视图中展示。

## 从邮件生成

### 入口

入口位于 Todo 面板右上角：

- 从邮件生成

点击后打开居中弹窗。

### 弹窗形式

采用一屏完成，不做分步向导。

弹窗中同时展示：

- 邮件内容粘贴区
- 分析邮件按钮
- Todo 建议列表
- 添加选中待办按钮

### 邮件输入

用户手动粘贴一封邮件内容。

输入区说明：

- 不连接真实邮箱。
- 不自动读取邮件。
- Demo 中使用模拟分析结果。

### 分析结果

点击“分析邮件”后，右侧或下方显示 Todo 建议列表。

每条建议支持：

- 勾选是否添加
- 编辑标题
- 编辑截止日期
- 编辑截止时间
- 编辑来源 / 课程

用户点击“添加选中的待办”后，选中的建议加入 Todo 数据。

### 空状态

当尚未分析或未识别到待办时，建议区显示空状态。

建议文案：

- 粘贴邮件后点击“分析邮件”，这里会出现 Todo 建议。

## Demo 数据说明

V0.3 Demo 使用本地模拟数据：

- Todo 数据为内存状态。
- 邮件分析结果为模拟生成。
- 添加、编辑、完成状态只在当前页面会话中生效。
- 刷新页面后不保证保留。

正式开发时应基于 React/Vite 项目实现，不直接复用 Demo 的单文件结构。

## 与 V0.2 的关系

V0.2 已确认并延续：

- Home 左右布局。
- 本周日程。
- 添加日程。
- Todo 新增、编辑、删除。
- 点击 Todo 卡片进入详情编辑。
- Links 搜索。
- 个人信息本地设置页。

V0.3 新增：

- Todo 系统视图。
- Home 默认 Todo 视图为“今天”。
- 每个系统视图显示数量。
- 从邮件生成 Todo 建议。
- 邮件建议一屏确认并添加。

V0.3 不处理：

- 常用入口置顶。
- ISSUE-004。
- 真实邮箱集成。
- 自动读取或自动添加 Todo。
