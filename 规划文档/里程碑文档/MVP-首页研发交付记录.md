## 已实现内容

### Home 工作台

- 默认进入 Home 页。
- Home 页展示顶部概览区。
- Home 页展示本周课表。
- Home 页展示基础待办事项。
- Home 页展示高频快捷入口：Moodle、Student Email、Allocate+。

### 左侧导航与分栏页

- 左侧导航包含 Home、学习相关、学校事务、生活支持、联系与帮助、校园生活、账号工具。
- 点击 Home 返回工作台。
- 点击分类进入对应导航分栏页。
- 导航分栏页只展示当前分类下的 Links。
- 导航分栏页不展示课表、待办事项和 Home 高频快捷入口。

### 本周课表

- 课表采用带纵向时间轴的周视图。
- 课程按星期和开始时间定位。
- 不同时间上课的课程在纵向位置上有明确区分。
- 当前日期列有轻微强调。
- 当前正在进行的课程支持绿色轻背景状态。
- 点击课程卡片可打开居中课程详情浮层。
- 课程详情浮层支持点击遮罩、关闭按钮和 Escape 关闭。

### 待办事项

- 支持新增待办。
- 支持完成 / 取消完成。
- 支持删除待办。
- 输入为空时添加按钮禁用。
- 待办数据使用浏览器 localStorage 本地保存。

### 学校入口 Links

- 每个入口展示名称、面向新生的说明和外部打开图标。
- 点击入口在新标签页打开对应页面。
- 链接数据目前为静态模拟 / 手动维护数据。

## 运行方式

```bash

```

安装依赖：

```bash

```

启动开发服务器：

```bash
npm run dev
```

默认访问：

```text
http://127.0.0.1:5173/
```

如端口被占用，可指定其他端口：

```bash
npm run dev -- --port 5174
```
