# V0.2 Todo 详情页缺少删除入口，较 MVP 发生功能回归

## 基本信息

- 编号：ISSUE-003
- 类型：bug
- 优先级：高 / P0
- 当前状态：已完成

## 背景说明

MVP Todo 支持新增、完成/取消完成、删除。V0.2 当前实现支持新增、编辑截止日期/时间、完成状态切换，但产品部在 Todo 详情弹窗中未发现删除入口，代码中也未看到删除 Todo 的交互。

产品部确认：点击对勾应表示完成 / 取消完成该事项，不应等同于删除。删除属于移除错误、重复或不再需要的 Todo，应作为独立操作放在点开事项之后的详细页面内。

影响：用户创建错误 Todo 后无法删除，核心待办流程不完整，较 MVP 发生功能回归。

## 建议处理方式

- 在点开 Todo 事项后的详情页面 / 详情弹窗内提供删除按钮。
- 保持对勾交互仅用于完成 / 取消完成 Todo，不承担删除语义。
- 删除前建议进行二次确认，避免误删。
- 删除后同步更新 localStorage 状态，确保刷新后被删除 Todo 不再出现。
