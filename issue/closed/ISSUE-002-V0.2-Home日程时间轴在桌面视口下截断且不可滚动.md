# V0.2 Home 日程时间轴在桌面视口下截断且不可滚动

## 基本信息

- 编号：ISSUE-002
- 类型：bug
- 优先级：高 / P0
- 当前状态：已完成

## 背景说明

产品部对 UniDock V0.2 正式实现进行验收时发现，研发交付说明中写明“日程显示早 8 点到晚 8 点，比例已缩小，桌面端不需要滚动查看完整时间范围”。但产品部在 `http://127.0.0.1:5175/`、1280x720 视口复验时发现，Home 的“本周日程”只能看到约 8:00-14:00 的内容，15:00-20:00 区域被截断。

技术观察：`.timeline-shell` 的 `clientHeight` 约 398px，`scrollHeight` 约 685px，且 `overflowY` 为 `hidden`，因此剩余时间段不可见也不可滚动。

影响：用户无法查看完整 8:00-20:00 日程范围，违背 V0.2 验收重点。

## 建议处理方式

- 调整 Home 日程时间轴在常见桌面视口下的高度、比例或布局，使 8:00-20:00 时间范围完整可见。
- 如果设计无法在目标视口完整显示，则必须提供局部滚动，且不能隐藏后续时间段内容。
- 保持 Home 页面整体布局稳定，避免修复后出现新的不可访问内容或主要模块溢出问题。
