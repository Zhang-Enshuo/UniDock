# UniDock MVP UI 设计 Spec

## 当前状态

本文件记录 UniDock MVP 静态 Demo 已确认的页面结构、交互方式和视觉要求，供研发部正式实现时参考。

当前 Demo 文件位于：

- `code/index.html`
- `code/styles.css`
- `code/app.js`

Demo 只用于确认界面与操作流程，不代表正式技术栈已经确定。

## 设计目标

UniDock MVP 是面向 UNSW / UNSW College 新生的个人学习工作台。

第一版要解决的核心问题是：学校入口分散、命名偏官方、新生查找成本高。界面需要让用户用较少判断成本完成：

1. 在 Home 页查看本周课表。
2. 在 Home 页处理基础待办事项。
3. 通过左侧导航进入不同学校入口分栏页。

## 信息架构

### 一级页面

MVP 采用单应用多状态结构，不做多页面复杂路由也可以实现，但用户感知上需要区分：

- Home 页
- 学习相关分栏页
- 学校事务分栏页
- 生活支持分栏页
- 联系与帮助分栏页
- 校园生活分栏页
- 账号工具分栏页

### Home 页

Home 页只展示：

- 顶部概览区
- 本周课表
- 待办事项
- 高频快捷入口：Moodle、Student Email、Allocate+

Home 页不展示完整 Links 区域。

### 导航分栏页

点击左侧某个分类后，进入对应导航分栏页。

导航分栏页只展示：

- 顶部概览区，说明当前分类
- 当前分类下的学校入口 Links

导航分栏页不展示：

- 本周课表
- 待办事项
- Home 页快捷入口

## 桌面端布局

### 总体结构

桌面端采用左侧固定导航 + 右侧内容区。

- 左侧导航栏宽度约 240px。
- 右侧内容区占满剩余横向空间，不使用过窄的最大宽度限制。
- 页面背景为浅灰白，内容容器为白色卡片。
- 页面整体是工作台风格，不是营销落地页。

### Home 页布局

Home 页右侧内容区采用：

- 顶部概览区：横向展示标题、说明、日期和快捷入口。
- 主工作区：课表和待办保持当前 Demo 的控件比例。

桌面端主工作区要求：

- 课表为主区域。
- 待办为右侧辅助区域。
- 当前控件布局比例保持稳定。
- 课表横向固定，不出现横向拖动或左右移动。
- 如果后续正式实现遇到较小宽度，可再讨论响应式折叠策略，但默认桌面体验应优先保证课表完整可读。

### 导航分栏页布局

导航分栏页右侧内容区采用：

- 顶部概览区：显示当前分类名称和简短说明。
- Links 卡片区：展示当前分类下的学校入口。

Links 不应和课表、待办混在同一页面状态下。

## 左侧导航栏

### 内容

左侧导航包含品牌区和页面入口。

品牌区：

- UniDock
- UNSW student hub

导航入口：

1. Home
2. 学习相关
3. 学校事务
4. 生活支持
5. 联系与帮助
6. 校园生活
7. 账号工具

### 交互

- 默认选中 Home。
- 点击 Home，右侧显示课表和待办。
- 点击其他分类，右侧切换为对应 Links 分栏页。
- 当前选中项使用浅黄色背景和强调边框。
- 分类项包含图标、中文名、英文辅助名。

## 顶部概览区

### Home 页文案

- 标题：今天要看的东西
- 说明：这里是 Home 页，只放本周课表、待办事项和几个高频入口。
- 日期：使用当前日期，例如 Friday 18 Sept。
- 快捷入口：Moodle、Student Email、Allocate+

### 分栏页文案

- Kicker：学校入口
- 标题：当前分类名
- 说明：这里是导航分栏页，只展示当前分类下的学校链接。

分栏页不展示快捷入口按钮。

## 本周课表

### 位置

课表只出现在 Home 页。

### 信息字段

每节课展示：

- 课程名称
- 星期
- 开始时间
- 结束时间
- 地点

### 布局

课表采用固定横向周视图：

- 顶部：周一到周五列头。
- 左侧：纵向时间轴。
- 中间：课程按星期和时间定位。
- 同一天不同时间的课程需要在纵向位置上有明确区分。
- 课程块高度根据课程时长计算，但必须设置最小高度，避免短课信息显示不全。
- 课表本体横向固定，不使用横向滚动作为桌面端默认体验。

### 视觉状态

- 当前日期列使用轻微黄色背景。
- 当前正在进行的课程可使用绿色轻背景。
- 普通课程为白色卡片、浅边框。

### 课程详情动效

点击课程卡片后，课程卡片放大居中显示。

交互要求：

- 点击课程卡片打开详情浮层。
- Enter / Space 也可以打开详情。
- 详情浮层显示课程名、星期、时间和地点。
- 点击关闭按钮、点击遮罩或按 Escape 关闭。

动效要求：

- 从原课程卡片位置放大到屏幕中央。
- 使用类似 macOS Dock / 窗口缩放的弹性动效。
- 背景加半透明遮罩和轻微模糊。
- 关闭时从居中卡片缩回原位置。

### 暂不做

- 周切换
- 日历视图切换
- 自动同步 Allocate+
- 课程提醒
- 出勤记录

## 待办事项

### 位置

待办事项只出现在 Home 页。

### 信息字段

每条待办展示：

- 待办内容
- 完成状态

### 操作

- 输入待办
- 新增待办
- 标记完成 / 取消完成
- 删除待办

### 交互细节

- 输入框为空时，添加按钮禁用。
- 按 Enter 可以新增待办。
- 已完成待办文字加删除线，并降低视觉权重。
- 删除按钮默认弱化，悬停或聚焦时明显。
- 空状态文案：还没有待办。把下一件要做的事写下来。

## Links 分栏页

### 位置

Links 只出现在导航分栏页，不出现在 Home 页。

### 卡片内容

每个入口卡片展示：

- 链接名称
- 面向新生的简短说明
- 外部打开图标

点击卡片打开对应学校页面。

### 分类与入口

学习相关：

- Moodle：课程资料、作业和学习内容入口。
- Allocate+：查看课表、选课和出勤相关信息。
- Academic Calendar：查看关键日期、假期和学期安排。
- Subject Enrolment Form：提交选课或科目登记相关表格。
- Student Progress Support：预约学业进度支持。

学校事务：

- Student Forms：查找并提交学生事务表格。
- Student ID Card：预约办理或更换学生卡。
- College Policies：查看学院政策和流程。
- FS UNSW Preferences：Foundation Studies 升学偏好相关入口。

生活支持：

- Accommodation Support：预约住宿相关支持。
- Wellbeing Support：预约身心健康支持。
- 24/7 Support on Campus：校园安全和紧急支持入口。

联系与帮助：

- Contact Us：不知道找谁时，从这里提交问题。
- Important Student Contacts：查看重要部门和支持联系方式。

校园生活：

- Campus Map：查找教室和校园地点。
- Events & Activities：查看校园活动和社团活动。
- Volunteering：查看志愿活动机会。

账号工具：

- Forgot zID Password：重置 zID 密码。
- Student Email：查看学校邮件和正式通知。

## 视觉风格

整体风格：

- 清爽
- 安静
- 有秩序
- 像个人学习工作台

避免：

- 大型营销 hero
- 过度装饰图
- 大面积夸张渐变
- 让 Home 页与导航分栏页内容混杂

### 配色

基础色：

- 页面背景：#F6F7F9
- 主内容背景：#FFFFFF
- 主文字：#172033
- 次级文字：#667085
- 边框：#E4E7EC

强调色：

- 主色：#FFD500 或接近 UNSW 黄色
- 深色强调：#1F2937
- 成功状态：#12B76A
- 危险操作：#D92D20

UNSW 黄色适合用于导航选中态、当前日期列和强调标签，不建议承载浅色文字。

### 圆角与阴影

- 卡片圆角：8px。
- 按钮圆角：8px。
- 输入框圆角：8px。
- 详情浮层可使用更大的圆角，例如 18px。
- 阴影保持克制，详情浮层可以使用更强阴影突出层级。

## 组件拆分建议

研发部正式实现时建议拆成：

- AppShell：页面整体框架。
- SidebarNav：左侧导航。
- OverviewHeader：顶部概览区。
- HomeDashboard：Home 页容器。
- WeeklyScheduleTimeline：时间轴课表。
- CourseBlock：课程块。
- CoursePreviewModal：课程详情放大浮层。
- TodoPanel：待办模块。
- TodoItem：待办列表项。
- LinkPage：导航分栏页容器。
- LinkCard：入口卡片。

## 数据结构建议

### 页面状态

```ts
type PageId =
  | 'home'
  | 'study'
  | 'admin'
  | 'support'
  | 'help'
  | 'campus'
  | 'account';
```

### 课程

```ts
type Course = {
  id: string;
  name: string;
  weekday: 'mon' | 'tue' | 'wed' | 'thu' | 'fri' | 'sat' | 'sun';
  startTime: string;
  endTime: string;
  location: string;
};
```

### 待办

```ts
type Todo = {
  id: string;
  title: string;
  completed: boolean;
};
```

### 链接

```ts
type UniLink = {
  id: string;
  categoryId: Exclude<PageId, 'home'>;
  title: string;
  description: string;
  url: string;
};
```

## MVP 验收标准

研发完成后应满足：

1. 默认进入 Home 页。
2. Home 页只显示顶部概览、本周课表、待办事项和高频快捷入口。
3. 点击左侧分类后，进入对应导航分栏页。
4. 导航分栏页只显示当前分类的学校入口，不显示课表和待办。
5. 课表为带纵向时间轴的周视图。
6. 不同时间上课的课程在纵向位置上有明确区分。
7. 课表横向固定，不在桌面端默认横向滚动。
8. 课程信息较长时不能被遮挡或截断到不可读。
9. 点击课程卡片能放大居中显示详情，并支持关闭。
10. 待办事项支持新增、完成、取消完成和删除。
11. 外部链接点击后打开对应学校页面。
12. 页面整体保持工作台风格。

## 当前 UI 结论

UniDock MVP 已确认采用「Home 工作台 + 左侧导航分栏页」结构。

Home 页服务日常查看与处理：课表、待办、高频入口。

导航分栏页服务查找学校入口：点击某个分类后，只展示该分类下的 Links。

正式开发时应以本文件和当前静态 Demo 为 UI / 交互基准。
