# UniDock MVP 首页 Spec

## 版本定位

UniDock MVP 是一个面向 UNSW / UNSW College 新生的个人学习工作台。

第一版重点解决的问题是：学校相关入口分散、命名偏官方、新生查找成本高。MVP 不尝试替代学校系统，而是把高频学习、事务、支持和校园生活入口重新组织成一个更容易使用的首页。

## 产品目标

让用户打开 UniDock 后，可以快速完成三件事：

1. 查看本周课程安排。
2. 记录和处理基础待办事项。
3. 通过左侧分类导航快速找到学校相关入口。

## 页面结构

MVP 采用左侧固定导航 + 右侧内容区的工作台式布局。

用户感知上分为两类页面状态：

1. Home 页
2. 导航分栏页

第一版不做复杂多页面系统，但需要在界面状态上明确区分 Home 和各个分类入口页。

### Home 页

Home 页只展示：

- 一周课表
- 基础待办事项
- 少量高频快捷入口，例如 Moodle、Student Email、Allocate+

Home 页不展示完整学校入口 Links。

### 导航分栏页

用户点击左侧分类后，进入对应导航分栏页。

导航分栏页只展示当前分类下的学校入口 Links。

导航分栏页不展示：

- 一周课表
- 基础待办事项
- Home 页快捷入口

## 模块一：一周课表

### 目标

帮助用户快速了解本周课程安排。

### MVP 范围

课表默认展示一周内容。

每节课至少包含：

- 课程名称
- 星期
- 开始时间
- 结束时间
- 地点

课表在 UI 上采用带纵向时间轴的周视图，不同时间上课的课程需要在纵向位置上有明确区分。

点击课程卡片时，可以放大居中展示课程详情。该交互属于 UI 展示效果，不代表第一版需要实现课程编辑、提醒或自动同步。

### 数据方式

第一版课表数据可以手动维护。

### 暂不支持

- 从 Allocate+ 自动同步课表
- 今天 / 本周 / 下周切换
- 日历视图切换
- 课程提醒
- 出勤记录

这些能力放入后续版本考虑。

## 模块二：基础待办事项

### 目标

帮助用户记录最基础的待处理事项。

### MVP 范围

待办事项第一版不做分类。

每条待办至少包含：

- 待办内容
- 完成状态

基础操作包括：

- 新增待办
- 标记完成 / 取消完成
- 删除待办

### 暂不支持

- 待办分类
- 截止日期
- 优先级
- 标签
- 提醒
- 多设备同步

这些能力放入后续版本考虑。

## 模块三：左侧分类导航栏

### 目标

按照新生的真实使用场景重新组织学校入口，降低查找成本。

### MVP 分组

#### 学习相关

- Moodle
- Allocate+
- Academic Calendar
- Subject Enrolment Form
- Student Progress Support

#### 学校事务

- Student Forms
- Student ID Card
- College Policies
- FS UNSW Preferences

#### 生活支持

- Accommodation Support
- Wellbeing Support
- 24/7 Support on Campus

#### 联系与帮助

- Contact Us
- Important Student Contacts

#### 校园生活

- Campus Map
- Events & Activities
- Volunteering

#### 账号工具

- Forgot zID Password
- Student Email

### 链接展示要求

每个链接入口应至少展示：

- 链接名称
- 简短说明
- 外部链接地址

说明文字应优先使用新生容易理解的表达，而不是完全照搬官网描述。

### 交互要求

- 默认进入 Home 页，展示课表和待办。
- 点击左侧分类后，进入对应导航分栏页，并展示该分类下的链接。
- 导航分栏页不展示课表和待办。
- 点击具体链接后，打开对应学校页面。
- 第一版不要求复杂动画。

## MVP 非目标

第一版暂不做以下内容：

- 用户登录
- 云端同步
- 多用户配置
- 多学校支持
- AI 校园助手
- 邮件聚合
- Moodle 作业同步
- Allocate+ 课表自动同步
- 移动端 App
- 后台管理系统

## 后续版本候选方向

后续可以考虑：

- 课表视图切换
- 常用入口置顶
- 最近打开记录
- 待办截止日期
- 待办分类
- 本地个性化配置
- 中英文显示切换
- 任务式入口，例如“我要上课”“我要求助”“我要办手续”

## 当前产品结论

UniDock MVP 由两个主要页面状态组成：

1. Home 工作台：一周课表、基础待办事项、高频快捷入口。
2. 导航分栏页：按照左侧分类展示学校入口 Links。

MVP 的核心价值是把新生日常高频任务和学校入口集中在一个清晰、轻量、可快速访问的首页中。
